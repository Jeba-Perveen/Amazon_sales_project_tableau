# Amazon Sales Dashboard

## Overview
This project is an interactive Tableau dashboard created to analyze Amazon sales data and generate business insights related to sales performance, profit trends, regional analysis, and product category performance.

The dashboard helps in understanding business performance through visual analytics and KPI tracking.

---

## Dashboard Features

- Revenue Analysis
- Profit Analysis
- Regional Performance Analysis
- Country-wise Sales Insights
- Product Category Analysis
- Sales Channel Comparison
- Trend Analysis
- Interactive Filters and KPIs

---

## Tools Used

- Tableau
- CSV Dataset
